# KOREA (코리아) - 1990년 도스 게임 이식 + 256색 개선판

1990년 PARK S.G. 님이 터보 C 로 만든 도스 게임 `KOREA.EXE` 를 역어셈블해서
C 로 옮기고, 화면과 소리를 새로 꾸민 판을 함께 만든 것입니다.
djgpp 로 빌드하는 32비트 DPMI 프로그램입니다.

두 가지로 빌드됩니다.

| 실행 파일 | 내용 |
| --- | --- |
| `KOREA.EXE` | 원판 그대로. 흑백 640x400 화면, PC 스피커 소리 |
| `KOREAVGA.EXE` | 256색 스프라이트, 애드립(OPL2) 음악, 부드러운 블록 움직임 |

## 게임

떨어지는 블록으로 줄을 채워 지우는 테트리스 형식입니다.
판 곳곳에 갇힌 사람을 줄을 지워서 모두 구하면 다음 스테이지로 갑니다.
스테이지는 100개이고 편집기로 고칠 수 있습니다.

조작

    왼쪽/오른쪽  옮기기        아래   한 칸 내리기
    위, 숫자판 5 돌리기        Space  바닥까지 떨어뜨리기
    F1           배경음악 켜기/끄기    Esc  끝내기

## 256색판에서 달라진 것

- VESA 256색 화면 (없으면 320x200 으로 내려감)
- 원판 흑백 그림 256개를 색칠한 스프라이트 (유리 벽돌, 태극기, 금색 테두리 ...)
- 첫 화면 KOREAN TETRIS 로고를 글자마다 다른 색으로
- 애드립 배경음악 (아리랑 록 편곡, 코로베이니키 메들리, 효과음)
- 블록이 옆으로 미끄러지고 Space 로 떨어뜨리면 가속하며 떨어짐
- 메뉴에 QUIT (원판의 만들다 만 두 메뉴 대신)

원판의 규칙, 스테이지, 속도는 그대로 두었습니다.

## 빌드

djgpp 가 있어야 합니다.

```
make -f korea.mak        # 둘 다
make -f korea.mak mono   # KOREA.EXE
make -f korea.mak vga    # KOREAVGA.EXE
```

## 파일

| 파일 | 내용 |
| --- | --- |
| `korea.c` | 전체 흐름과 상태 |
| `menu.c` `editor.c` `game.c` `board.c` `text.c` `system.c` | 첫 화면, 스테이지 편집기, 게임 진행, 판 그리기, 글자 찍기, 파일/키/시간 |
| `data.c` | 원판 데이터 영역에서 뽑은 표 (화면, 블록 모양, 악보 ...) |
| `vidmono.c` `vid256.c` | 흑백 화면 / 256색 화면 |
| `music.c` `musvgm.c` | PC 스피커 / 애드립 음악 |
| `listing.asm` | 원판 실행 파일 역어셈블 결과 (주석 달아 둔 것) |
| `tools/mkspr256.py` | `KOREA256.SPR` (256색 스프라이트와 팔레트) 만들기 |
| `tools/mkmusic.py` | 애드립 곡과 효과음을 `SOUND.DAT` 로 묶기 |
| `tools/mkrelease.py` | `release/` 배포 폴더 만들기 |

`KOREA.PTN` (16x16 그림 256개) 과 `KOREA.STG` (스테이지 100개) 는 1990년 원본 파일입니다.

## 실행

DOSBox 나 도스에서 그 폴더로 가서 `KOREA` 또는 `KOREAVGA` 라고 칩니다.
`CWSDPMI.EXE` 가 같은 폴더에 있어야 합니다.
